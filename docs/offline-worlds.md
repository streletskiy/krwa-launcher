# Офлайн-миры KRWA

Управление находится на сайте KRWA в разделе **Админка → Быстрые действия → Офлайн-миры**. Постоянный адрес — [mc.krwa.ru/admin/offline-worlds](https://mc.krwa.ru/admin/offline-worlds). Для просмотра и решений нужна роль администратора Aster. По умолчанию никто не может скачать участок или отправить изменения. Выдавайте доступ доверенным игрокам. Локальное сохранение можно отредактировать вне Minecraft, поэтому сверка двух версий не доказывает происхождение предмета.

## Разрешить игроку поездку

1. Игрок заходит в обычный мир Aeronautics, выходит из игры на нужном участке и в лаунчере нажимает **Офлайн-мир → Запросить доступ**.
2. Администратор видит игровой ник и координаты центра. Проверьте владельца территории, приваты и соседние базы. Разрешение действует на квадрат 5 × 5 чанков, включая все высоты. Координаты центра округляются до центра чанка.
3. Нажмите **Разрешить**. Для выдачи доступа заранее или изменения участка введите игровой ник и координаты X/Z в форме. Перенос разрешения на другую территорию доступен после завершения активной поездки. **Отозвать** немедленно закрывает доступ через сервис и незавершённую поездку. Уже скачанный мир остаётся у игрока.

## Перед полётом и после него

Войдите в KRWA Launcher на устройстве с интернетом. Выберите Aeronautics, затем **Офлайн-мир → Скачать для офлайна**. Оставайтесь в окне, пока лаунчер проверяет Java, моды, файлы и свободное место. Если окно закрыли, с ожидающей поездкой можно продолжить. Для первоначальной загрузки сборки потребуется место сверх размера самого сохранения.

**Играть офлайн** открывает отдельное сохранение с персонажем игрока. До отъезда проверьте его с отключённым Wi‑Fi. На Steam Deck работают крестовина или стик, A выбирает действие, B закрывает окно. После поездки сохранитесь, закройте Minecraft, подключитесь к сети и нажмите **Синхронизировать**. После обрыва нажмите **Проверить отправку**. Лаунчер хранит ту же посылку до подтверждения. Архив защищён контрольной суммой и привязан к профилю и поездке. Пока отправка идёт, поездка закрыта для дальнейшей игры через лаунчер.

Снимок затрагивает сохранённые чанки разрешённого участка и данные самого игрока. При экспорте сервис просит сервер сохранить мир на диск, затем дважды считывает участок и сверяет содержимое каждого файла по SHA-256. Снимок выдаётся только при совпадении. Автосохранение сервера продолжает работать. Другие игроки могут продолжать игру. Для записи изменений сервис ожидает пустого сервера, штатно останавливает его через Crafty, получает файловую блокировку Minecraft, делает копии изменяемых файлов и перезапускает сервер. Пока игроки онлайн, отправка остаётся в очереди.

## Разобрать конфликт

Откройте поездку со статусом **Нужно решение**. На карте север сверху. Нажмите на чанк и выберите **Конфликты**. У записи показаны X/Y/Z и три значения — исходное, текущее серверное и присланное игроком. **Показать на карте** открывает соответствующий горизонтальный срез. Белая рамка указывает выбранный блок, янтарная — изменённые позиции. Наведение показывает идентификатор блока каждого варианта.

- **Применить версию игрока** — принять показанные поддерживаемые изменения всей поездки. Перед записью сервис ещё раз проверяет текущий мир. Изменившееся сравнение требует нового решения.
- **Вернуть игроку на доработку** — оставить сервер в текущем состоянии, разрешить исправить ту же локальную копию и отправить её снова.
- **Оставить мир сервера** — закрыть поездку целиком. Внесённые в самолёте изменения останутся в сохранении на устройстве.
- Для ручного разбора можно скачать исходный снимок, серверные чанки на момент сравнения и присланный архив. Серверный архив содержит выделенные чанки для сравнения. Проверяйте ручной перенос на отдельной копии.

Обычные совместимые изменения переносятся автоматически. Первая версия поддерживает обычные строительные материалы, часть ванильных предметов и инструментов, опыт и изменения содержимого уже существующих обычных сундуков и бочек. При конфликте экономические данные и блоки рассматриваются как одна поездка. Для произвольного модового NBT, технических блоков и неподдерживаемых предметов автоматическая запись заблокирована. Движущиеся механизмы, сущности, другие измерения, командные квесты и глобальные данные модов не входят в перенос. Номер сборки на сервере и в поездке должен совпадать.

## Эксплуатация

Служба работает под учётной записью, которой доступен локальный адаптер Crafty. Файл конфигурации для `world-sync/start.ps1` задаёт абсолютные пути в полях `World`, `Data`, `CraftyHelper`, `Distribution`, `Python` и UUID экземпляра в `ServerId`. Каталог `Data` должен находиться вне HTTP-репозитория и быть доступен только службе и администраторам хоста. Экземпляры запускаются с одним рабочим процессом Uvicorn. HTTPS-запросы проходят через Caddy, доступ проверяется по Aster.

В каталоге данных `trips.sqlite3` хранит разрешения, поездки и журнал решений. Подкаталог с идентификатором поездки содержит её снимки и сравнение. Каталог `rollback` содержит точные исходные файлы перед записью. Если запись прервётся, служба восстановит файлы перед перезапуском Minecraft. При ручном восстановлении остановите службу и Minecraft, сохраните текущий мир отдельно и сверьтесь с `rollback/files.json`. Возврат старого полного региона после возобновления игры может откатить более поздние изменения других игроков.
