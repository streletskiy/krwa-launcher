# Офлайн-миры KRWA

Управление находится на сайте KRWA в разделе **Админка → Офлайн-миры**. Постоянный адрес — [mc.krwa.ru/admin/offline-worlds](https://mc.krwa.ru/admin/offline-worlds). Для просмотра и решений нужна роль администратора Aster. По умолчанию никто не может скачать участок или отправить изменения. Выдавайте доступ доверенным игрокам. Локальное сохранение можно отредактировать вне Minecraft, поэтому сверка двух версий не доказывает происхождение предмета.

## Подготовить мир

Администратор выдаёт доступ по игровому нику или одобряет запрос игрока. Разрешение открывает все сохранённые территории и измерения, включая модовые, зерно генерации, постройки и содержимое контейнеров. Профили других игроков остаются на сервере.

Откройте **Настройки → Офлайн-поездки**. Выйдите с игрового сервера, нажмите **Скачать для офлайна** и выберите **Только подготовить** или **Подготовить и играть**. Полоса показывает объём полученных файлов. После обрыва снова откройте поездку, чтобы продолжить с проверенных файлов.

Без сети лаунчер использует сохранённый аккаунт и установленную сборку. **Продолжить поездку** открывает скачанный мир сервера. **Открыть Minecraft** ведёт в главное меню, где можно выбрать свой мир или создать новый. Эти сохранения остаются на устройстве.

## Вернуть изменения

Для новых поездок обработка начинается автоматически, когда на сервере нет игроков. При следующем входе персонаж окажется на координатах и в измерении, где он сохранился в поездке. Сервер проверяет, что целевой чанк существует. Инвентарь и добычу из контейнеров он переносит вместе. При пересечении обычных правок одного блока сохраняется онлайн-версия, а офлайн-вариант остаётся в архиве. Спорные предметы, транспорт или недоступное место возвращения попадут на проверку администратору.

Сохранитесь и закройте Minecraft. Подключитесь к сети и откройте **Настройки → Офлайн-поездки → Отправить изменения**. После обрыва нажмите **Продолжить отправку**. Пока изменения на проверке, можно открыть личную копию для одиночной игры. Когда сервер подтвердит запись в мир, лаунчер при подключении уберёт скачанную поездку и пакет отправки. Личные копии останутся в Minecraft. Если после отправки исходное сохранение изменилось, лаунчер перенесёт его в личные миры.

Служба сравнивает исходный снимок, изменения игрока и текущий мир. Она возвращает поддерживаемые блоки, предметы и опыт, новые критерии достижений и прогресс FTB Quests. В поездке участник команды получает её прогресс и собственную историю наград. Смена команды и пересекающиеся выдачи наград требуют ручной проверки. Правила крипера и сохранения опыта действуют и в одиночном мире поездки.

Когда основной сервер свободен, служба останавливает его, блокирует мир, сохраняет резервные копии изменяемых файлов и перезапускает сервер. Новые чанки и изменения модовых сущностей могут потребовать ручного переноса.

## Разобрать конфликт

Откройте поездку со статусом **Нужно решение**. Сразу под заголовком показано количество совместимых правок, конфликтов и записей для ручного переноса. **Автослияние** применяет совместимую часть и оставляет серверные версии остальных записей. Архив игрока сохраняется. Если хотите принять отдельные конфликты, укажите **Взять у игрока** в нужных строках и нажмите **Применить выбранное**. После подтверждения сервер снова сравнит исходные данные. Карта и срезы открываются по запросу.

- **Принять все конфликты игрока** — принять показанные поддерживаемые изменения всей поездки. Перед записью сервис ещё раз проверяет текущий мир. Изменившееся сравнение требует нового решения.
- **Вернуть игроку на доработку** — оставить сервер в текущем состоянии, разрешить исправить ту же локальную копию и отправить её снова.
- **Оставить мир сервера** — закрыть поездку целиком. Внесённые в самолёте изменения останутся в сохранении на устройстве.
- Для ручного разбора можно скачать исходный снимок, серверные чанки на момент сравнения и присланный архив. Серверный архив содержит выделенные чанки для сравнения. Проверяйте ручной перенос на отдельной копии.

Обычные совместимые изменения переносятся автоматически. Первая версия поддерживает обычные строительные материалы, часть ванильных предметов и инструментов, опыт и изменения содержимого уже существующих обычных сундуков и бочек. При конфликте экономические данные и блоки рассматриваются как одна поездка. Для произвольного модового NBT, технических блоков и неподдерживаемых предметов автоматическая запись заблокирована. Лодки, лодки с сундуками и обычные, грузовые, загрузочные и печные вагонетки сравниваются по UUID. Создание, перемещение между чанками и удаление совместимы с автослиянием. Перед подготовкой снимка выйдите из транспорта на сервере. Если закончить поездку за рулём обычной лодки или вагонетки, она вернётся в мир. Транспорт, в котором на сервере сидит игрок, остаётся для ручного разбора. Одновременное изменение одного транспорта требует решения администратора. Для пассажиров, нераспакованных таблиц добычи и неподдерживаемого груза доступен ручной разбор. Сборки Create Aeronautics на Sable рассматриваются отдельным набором для каждого измерения. Администратор может принять весь проверенный набор, если транспорт на сервере не менялся с момента выезда. При расхождении набор сохраняется в архиве для ручного переноса. Произвольные сущности других модов остаются в сохранении поездки. Номер сборки на сервере и в поездке должен совпадать.

## Эксплуатация

Служба работает под учётной записью, которой доступен локальный адаптер Crafty. Файл конфигурации для `world-sync/start.ps1` задаёт абсолютные пути в полях `World`, `Data`, `CraftyHelper`, `Distribution`, `Python` и UUID экземпляра в `ServerId`. Для записи учётной записи службы нужны права чтения и записи на `session.lock` и изменения в `playerdata`, `advancements`, `ftbquests` и каталогах `region`, `entities`, `sublevels` измерений, а также на файлы `data/sable_sub_level_{occupancy,force_load_tickets}.dat`. Каталог `Data` должен находиться вне HTTP-репозитория и быть доступен только службе и администраторам хоста. Экземпляры запускаются с одним рабочим процессом Uvicorn. HTTPS-запросы проходят через Caddy, доступ проверяется по Aster.

В каталоге данных `trips.sqlite3` хранит разрешения, поездки и журнал решений. Подкаталог с идентификатором поездки содержит её снимки и сравнение. Каталог `rollback` содержит точные исходные файлы перед записью. Если запись прервётся, служба восстановит файлы перед перезапуском Minecraft. При ручном восстановлении остановите службу и Minecraft, сохраните текущий мир отдельно и сверьтесь с `rollback/files.json`. Возврат старого полного региона после возобновления игры может откатить более поздние изменения других игроков.
