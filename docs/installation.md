# Установка и запуск KRWA Launcher

Выберите сборку для своей платформы. Постоянные ссылки ведут на актуальную стабильную версию. [Скачать лаунчер](../README.md#скачать).

## Windows и macOS

Сборки для Windows и macOS распространяются без подписи издателя. В Windows SmartScreen может показать предупреждение. В macOS лаунчер сообщает о новой версии и открывает ссылку на актуальный DMG для ручной установки. Windows- и Linux-сборки обновляются автоматически.

## Linux

Перед запуском AppImage разрешите выполнение файла через его свойства или командой `chmod +x`. Если система сообщает об отсутствии `libfuse.so.2`, см. [инструкцию AppImage по FUSE](https://docs.appimage.org/user-guide/troubleshooting/fuse.html).

DEB предназначен для Debian и Ubuntu, пакет `.pacman` — для Arch Linux. Для SteamOS используйте AppImage.

## Steam Deck

Откройте AppImage в Desktop Mode при запущенном Steam. Лаунчер установит AppImage в домашний каталог, создаст ярлык на рабочем столе и добавит игру с обложками в библиотеку Steam. Настройки существующего ярлыка сохраняются. Если обложки не появились, перезапустите Steam. Повторную установку можно запустить в настройках лаунчера.

Пока Controlify или Dynamic FPS выключены, главный экран предлагает включить их. Переключатели обоих модов находятся вверху вкладки «Моды».

Для управления стиками в Desktop Mode запустите ярлык из библиотеки Steam. В Desktop Mode и Gaming Mode используйте раскладку Steam Input **Gamepad**.

| Кнопка или действие | Что делает |
|---|---|
| Левый стик или крестовина | Перемещает фокус |
| **A** / **B** | Подтверждает действие / возвращает назад |
| **LB** / **RB** | Переключает вкладки настроек |
| Правый стик | Прокручивает |
| **A** или **X** в поле ввода | Открывает клавиатуру Steam |

Сочетание **STEAM + X** тоже открывает клавиатуру, когда его обрабатывает Steam. [Справка Steam Deck](https://help.steampowered.com/en/faqs/view/671A-4453-E8D2-323C/).

В Minecraft откройте чат через круговое меню Controlify. Клавиатура переключается между кириллицей и латиницей кнопками **РУС** и **ABC**.

## Игра и аккаунт

- При запуске лаунчер устанавливает и проверяет Java, Minecraft, NeoForge, библиотеки и моды. На главном экране видны этап подготовки, прогресс и число загружаемых файлов.
- Управляйте необязательными модами во вкладке «Моды». При обновлении модпака лаунчер сохраняет пользовательские настройки, создаёт локальную резервную копию и добавляет сервер в `servers.dat` с сохранением существующих записей.
- Зарегистрировать аккаунт, восстановить доступ, сменить пароль и загрузить скин можно в лаунчере. Авторизация работает через AsterYggdrasil.
- Интерфейс поддерживает русский, английский и польский языки и может выбирать язык системы.
